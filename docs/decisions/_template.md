# 决策记录模板

> 使用方法：复制本文件为 `docs/decisions/YYYY-MM-DD-简短标题.md` 后填写；创建后同步在 `docs/decisions/README.md` 索引追加一行。
> 修订双路径：小补充/实况追记 = 文末追加 `### 追记 YYYY-MM-DD` 节并同步状态行；方向性推翻 = 不覆盖旧记录，另建新条并互相引用，旧条状态行改「已被 <新决策文件名> 取代」。
> 部分取代：旧条状态行只写「部分条款已被 <文件> 取代」，明细归新条。评估类记录（spike/选型）可将「被否决的替代方案」并入「选择理由」。

- 状态：提议中 / 已生效 / 已被 <新决策文件名> 取代
